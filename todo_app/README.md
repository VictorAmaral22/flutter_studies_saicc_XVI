# TODO App — SAICC XVI

Aplicativo de referência do mini-curso de Flutter.

## Executar

```bash
flutter pub get
flutter run
```

## Tema

Edite a cor semente em `lib/theme/app_theme.dart`, gerada/inspirada no
[Material Theme Builder](https://material-foundation.github.io/material-theme-builder/).

## Funcionalidades

- Adicionar tarefas (bottom sheet)
- Concluir (checkbox ou tap)
- Excluir (ícone ou swipe)
- Limpar concluídas
- Empty state
- Light / Dark conforme o sistema
- Largura máxima em telas largas

Roteiro completo: [`../docs/hands-on.md`](../docs/hands-on.md).
